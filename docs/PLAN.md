# PLAN — 무엇을, 왜, 어디까지

> **언제 채우나:** 담당자 인터뷰 끝난 직후 (10:25~10:40). 구현 시작 전에 반드시.
> **누가:** Codex가 초안 → 내가 고침 → 담당자에게 확인.
> **왜:** 이 문서가 "만들 것"의 울타리. Codex는 여기 적힌 것만 만듦. 심사자도 이걸 보고 "결과물이 요구에 맞나"를 판단.
