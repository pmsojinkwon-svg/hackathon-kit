# QUESTIONS — 서술형 6문항 대비 질문 뱅크

> **언제 보나:** 오늘 연습 때 + 제출 직전(12:45) DECISIONS 읽으면서 "내 결과물에 해당하는 5개" 골라 입으로 답해보기. 시험 중엔 안 봄.
> **왜:** 서술형은 내 작업 기록 기반으로 생성됨. 코파톤 실측에서 "인지" 축이 전원 최저였음 = 여기가 상승 여지.
> 출처: hamjoon2003/sk-hynix-2nd-harness 질문 뱅크를 가져와 우리 키트 용어로 맞춤.

## 답변 틀 (4단, 5분 안에 4~6문장)

```
① 뭘 선택했나        "문제에는 X라고만 있었고, 저는 Y로 정했습니다."
② 왜 적절한가        "Z 때문입니다."                       ← 점수 구간
③ 약점은 뭔가        "대신 W인 경우엔 틀립니다."             ← 신뢰 구간
④ 다음엔 뭘 할 건가   "그래서 다음엔 V를 확인/개선하겠습니다."
```

**약점을 먼저 말하는 사람이 신뢰를 얻는다.** 숨기면 다음 문항에서 드러난다.

## 세 가지 금지

| 금지 | 대신 |
|---|---|
| 모르는 걸 아는 척 | "그건 확인하지 않았습니다. 확인하려면 A를 보면 됩니다." |
| "테스트했습니다" (근거 없이) | "TEST_LOG에 N개 항목이 OK였고, 미확인 M개는 HANDOFF에 적었습니다." |
| AI 탓 / 시간 탓 | "제가 X를 안 만들 것으로 뒀습니다. 이유는 Y입니다." |

## 질문 뱅크 22개

### 의도 — 가장 많이 나온다
1. 이 결과물의 **사용자는 누구고, 어떤 결정을 개선**합니까?
2. 무엇을 **반드시 지켜야 하는 조건**으로, 무엇을 **조정 가능한 것**으로 나눴습니까? 왜?
3. 문제에 **명시되지 않은 것 중 무엇을 가정**했습니까? 그 가정이 틀리면 뭐가 깨집니까?
4. **하지 않기로 한 것**은 무엇이고 왜입니까? → PLAN "안 만들 것"
5. Codex에게 무엇을 시켰고 무엇을 직접 했습니까? 그 경계를 어떻게 정했습니까?
6. Codex의 출력을 **어디서 신뢰하지 않았습니까?** 어떻게 검증했습니까? → TEST_LOG, review 결과
7. 작업을 어떻게 쪼갰습니까? 왜 그 단위였습니까? → 커밋 기록
8. 중간에 방향을 바꾼 적이 있습니까? 무엇을 보고 바꿨습니까? → DECISIONS

### 기술
9. 이 코드가 **실제로 어디서 어떻게 실행**됩니까? 명령 한 줄로. → `node server.js`
10. 같은 입력에 **같은 출력**이 나온다는 걸 어떻게 보장합니까?
11. 예외·실패 상황에서 어떻게 됩니까? 그게 일어났다는 걸 사용자가 압니까?
12. 비밀정보와 개인정보를 어떻게 다뤘습니까?
13. 데이터가 **10배** 오면 어디가 먼저 무너집니까?
14. 이 구조를 고른 이유는? **더 단순한 대안**은 왜 부족했습니까? → DECISIONS "다른 방법"
15. 테스트가 실패하는 걸 **직접 본 적**이 있습니까? 어떤 테스트였습니까? → TEST_LOG의 FAIL 줄

### 인지 — 전원 최저였던 축
16. 이 결과물에서 **가장 약한 부분**은 어디입니까? → HANDOFF "남은 한계"
17. **어떤 입력에서 틀린 답**을 냅니까? 하나만 구체적으로.
18. 지금 코드에서 **설명 못 하는 줄**이 있습니까?
19. 다시 한다면 무엇을 다르게 하겠습니까?
20. 시간이 2배 있었다면 무엇을 했겠습니까? 왜 그게 우선순위입니까? → HANDOFF "다음에 할 일"
21. 이 결과가 **실제 업무 목표**와 어떻게 연결됩니까? → PLAN "문제"
22. 이 결과를 내일 실무에 넣는다면, 무엇을 먼저 확인해야 합니까?

## 12:45에 문장으로 미리 써둘 답 3개 (종이에)

### ① 범위를 어떻게 잘랐나
> "담당자가 말한 것 중 ___와 ___를 이번에 만들고, ___는 뺐습니다. 뺀 이유는 ___입니다."

### ② 가장 위험한 실패 하나
> "___인 입력에서 틀립니다. 이유는 ___이고, HANDOFF '남은 한계'에 적어뒀습니다. 고치려면 ___가 필요한데 시간 안에 안 된다고 판단했습니다."

### ③ Codex를 어디서 믿지 않았나
> "___는 Codex에게 맡겼고, ___는 제가 직접 확인했습니다. 특히 ___는 Codex가 '됩니다'라고 했지만 ___로 다시 확인했습니다."

## 연습 방법 (오늘 저녁)
1. 모의 과제 끝나면 위 22개 중 5개를 골라 소리 내어 답한다
2. 답하다 막히면 → **그건 문서에 안 적힌 것.** DECISIONS/HANDOFF에 한 줄 적는다
3. 연습 목적은 말을 매끄럽게 하는 게 아니라 **문서의 구멍을 찾는 것**
