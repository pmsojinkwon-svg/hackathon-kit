# TEST_LOG — 뭘 어떻게 확인했나

> **언제 채우나:** Codex가 기능 하나 끝낼 때마다 (AGENTS.md 3번), `verify` 스킬 돌릴 때마다 자동으로.
> **왜:** 심사자가 "검증 루프를 설계했나"를 봄. 확인 기록이 많을수록 유리. 확인 안 한 건 **"미확인"**으로 솔직하게 — 거짓 OK는 문서·코드 대조에서 걸림.

---

|---|---|---|---|
| 예) 10:42 | 서버 기동 | `node server.js` | OK, 3000 포트 |

| 예) 11:20 | 빈 CSV 올렸을 때 | 빈 파일로 실행 | FAIL - 화면이 안 뜸 |
| | | | |

**결과 표기:** `OK` / `FAIL - (무엇이 어떻게 다른지)` / `미확인 - (이유)`
